# 知识库规则范式

## 目录结构

```
knowledge/
├── raw/                    # 原始资料层：只读，大模型绝不修改
│   ├── *.docx/pptx/pdf/xls # 原始文档
│   ├── *.md                # 原始文档的格式转换件（供大模型读取）
│   └── assets/             # 图片附件
├── wiki/                   # 知识库 Wiki 层：大模型全权维护
│   ├── content/            # 内容摘要词条
│   ├── entity/             # 实体词条（设备/部件）
│   ├── concept/            # 概念词条（参数/指标/规程/方案/技术/告警规则/设计规则）
│   ├── comparative/        # 对比分析词条
│   ├── overview/           # 总览综述词条
│   ├── index.md            # 内容索引（自动更新）
│   └── log.md              # 操作日志（仅追加）
├── CLAUDE.md               # 本文件：规则范式层
└── 知识库方法说明.md        # 体系架构说明
```

## 核心规则

### 原始资料层（raw/）
- **只读**：大模型仅读取使用，绝不修改 raw/ 下的任何文件
- 新资料入库时，先将文件放入 raw/，再在 wiki/ 中生成词条

### 知识库 Wiki 层（wiki/）
- 大模型全权负责创建、更新、维护
- 词条类型：内容摘要、实体词条、概念词条、对比分析、总览综述
- 每次新增资料后，同步更新 index.md 和 log.md
- 一份新资料应联动更新 10~15 个相关词条

### 资料入库流程
1. 用户上传文件后，将该资料放入 `raw/`
2. 大模型通读资料，确认核心要点
3. 在 `wiki/` 中生成专属摘要词条
4. 更新 `wiki/index.md` 索引
5. 同步修订 wiki/ 中所有相关实体、概念词条
6. 在 `wiki/log.md` 追加入库记录

### 知识问答规则
- 基于已有 wiki/ 词条检索回答，标注来源引用
- 优质问答结果可归档为 wiki/ 新词条
- 支持多种输出格式：Markdown、对比表格、Marp 幻灯片等
- 对于根因分析类问题，回答给出因果推理追溯链

### 定期规整
- 排查词条间矛盾、过时信息、孤立词条
- 补充缺失的交叉引用和独立词条
- 推荐待探究问题和待补充资料
