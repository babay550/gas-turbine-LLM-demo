# 燃气轮机智能运维知识库方法说明

## 体系架构

本知识库基于 Karpathy 知识管理范式，采用文件系统驱动的知识管理体系。

核心思想：**原始资料与加工知识分离，大模型作为知识管理员全权维护 Wiki 层。**

## 文档流转

```
用户上传文档 → raw/ 存储 → LLM 解析提取 → wiki/ 词条生成 → index.md 索引更新
                                          → log.md 日志追加
                                          → 关联词条联动更新
```

## 词条体系

### 词条类型

| 类型 | 目录 | 说明 |
|------|------|------|
| 内容摘要 | wiki/content/ | 文档核心内容摘要，1份文档对应1条 |
| 实体词条 | wiki/entity/ | 设备/部件实体，如"压气机叶片""DLN燃烧器" |
| 概念词条 | wiki/concept/ | 参数、指标、规程、方案、技术、报警规则、设计规则 |
| 对比分析 | wiki/comparative/ | 多方案/多设备/多标准对比 |
| 总览综述 | wiki/overview/ | 某一主题的全景概述 |

### 词条文件格式

每个词条为独立 Markdown 文件，包含 YAML frontmatter 和正文：

```markdown
---
id: "W001"
title: "词条标题"
type: "content_summary"
category: "压气机"
tags: ["标签1", "标签2"]
equipment: "关联设备"
severity: "高|中|低"
source_file: "raw/xxx.docx"
related_entries: ["W002"]
concept_subcategory: null
created: "2026-05-13"
updated: "2026-05-13"
---

## 正文内容
...
```

## 知识检索

- 基于 frontmatter 字段（title/tags/category）+ 正文内容进行全文检索
- 知识问答时先检索相关词条，再由 LLM 基于词条内容生成回答
- 所有回答标注来源词条，支持溯源验证

## 维护规则

1. **raw/ 层不可变**：原始文档一旦存入，不做任何修改
2. **wiki/ 层可演进**：LLM 可根据新资料更新已有词条
3. **index.md 可重建**：索引文件可从词条文件完全重建
4. **log.md 仅追加**：操作日志不可修改或删除已有记录
