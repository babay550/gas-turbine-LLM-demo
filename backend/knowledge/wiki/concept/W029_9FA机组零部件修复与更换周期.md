## 周期标准
以PG9351FA机组为例，主要零部件修复与更换周期如下（CI=燃烧检查，HGPI=热通道检查）：

### 燃烧系统部件
| 部件名称 | 修复周期 | 更换周期 |
| :--- | :--- | :--- |
| 燃烧室火焰筒 | CI | 5(CI) |
| 过渡段 | CI | 5(CI) |
| 燃料喷嘴 | CI | 3(CI) |
| 联焰管 | CI | 1(CI) |

### 热通道部件
| 部件名称 | 修复周期 | 更换周期 |
| :--- | :--- | :--- |
| 一级喷嘴 | HGPI | 2(HGPI) |
| 二级喷嘴 | HGPI | 2(HGPI) |
| 三级喷嘴 | HGPI | 3(HGPI) |
| 一级动叶 | HGPI | 2(HGPI) |
| 二级动叶 | HGPI | 3(HGPI) |
| 三级动叶 | HGPI | 3(HGPI) |

注：实际执行中需结合运行情况适当调整。一级动叶需评估保护涂层剩余寿命。
